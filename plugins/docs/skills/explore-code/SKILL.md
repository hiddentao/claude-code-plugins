---
name: explore-code
description: Explores and analyzes a codebase.
---

When exploring and analyzing a codebase look out for:

* Code organization and structure
  * High-level separation of concerns and organization of aspects
  * Lower-level organization of modules, files, methods, classes, etc
* Coding style and guidelines
  * Conventions and paradigms in use in the codebase
  * Design patterns in use and to be aware of
* Third-party frameworks and libraries
  * How they are used within the codebase and the implications for the codebase design
  * How they are installed/combined/etc
* Error handling
  * Backend error reporting back to frontend
  * Frontend error handling
* Logging
  * Logging to cloud (if there)
* Performance-oriented design
  * How performance is optimized for (if so)
  * Whether performance metrics are captured or capture-able
* Security practices and concerns
  * Key points to ensure security when using the code
  * Security decisions and trade-offs that have been made
* Build and deployment
  * How the code is to be built and deployed (if applicable)
* CLI scripts
  * Command-line scripts and their usage
* Test coverage
